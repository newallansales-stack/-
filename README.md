# 芯价 · 中国硬件价格观察站

内存条、显卡、CPU 和存储的价格看板：按型号、品牌、规格搜索，观察每日价格、周 K 线、月 K 线及**已收录记录中的历史最低价**。

## 固定在线网址与独立文件

免费 GitHub Pages 展示版的发布流程见 [发布说明](docs/publishing.md)。公开版只发布 66 个型号 / 参考配置的规格目录、分析与对比，**所有未经核实的价格均为空，显示“待核验”**。此前模拟现价、历史低价、涨跌与曲线已经撤下。网页不依赖临时 API 服务；在线导入与自动采集需另行部署下方的完整版。

规格包括内存的总容量、每条容量、条数、MT/s、I/O 时钟和 CL；显卡区分 23 个消费级条目与 5 款专业卡；CPU、SSD、机械硬盘各自展示对应参数。可筛选规格并同时对比最多 3 款同品类产品。目录不是在售清单，精确料号与可购价格还需逐项取得商家证据。参见 [规格口径](docs/specifications.md) 和 [全量价格核验](docs/price-audit.md)。

```bash
npm ci
npm run build:pages
```

输出为 `pages/index.html`，也可以下载该独立 HTML 文件后在浏览器中直接打开。不要直接用文件预览器打开仓库根目录的开发入口 `index.html`；它需要 Vite 编译和后端服务。

## 运行

需要 Node.js 24+（使用内置 SQLite，无需独立数据库服务）。

```bash
cd /workspace/-
npm ci --cache /workspace/.cache/npm
npm run build
npm start
```

服务端口默认为 `3001`，同一服务提供网页与 API。开发模式运行 `npm run dev`，启动 Vite（5173）及 API（3001），支持热更新。`npm test` 执行后端及 HTTP 集成测试。

## 数据的真实覆盖范围

**本次成功核验的真实人民币在售报价为 0 条，成交记录为 0 条。** 公开网页仅显示规格目录和待核验状态，不发布模拟价格。原页面的 ¥721 等数字来自合成公式，没有可购买链接，不能作为实际交易或历史低价证据。

完整后端保留显式开发测试用的 66 型号模拟数据，默认先进入真实记录工作区。`mode=demo` 只供开发和聚合测试；公开构建的默认导出函数不读取数据库，不打包这些模拟记录或用户真实数据。核查请求被电商网络策略拒绝或返回上游错误，精确域名已加入环境配置草稿，需在环境设置保存生效后继续重试。

真实记录工作区与演示记录隔离。2020 年以来的完整逐日全网数据没有找到可靠的免费公开源，缺失日期不会自动生成价格。已在线搜索并检查多个 GitHub 项目的数据、许可证和 API 实现，详见 [公开来源调查](docs/research.md)：

- [docyx/pc-part-dataset](https://github.com/docyx/pc-part-dataset)：MIT，28,063 条相关硬件记录，但属于 2025-07-23 的 **USD 单次快照**，不能当作中国每日人民币历史。
- [guidajia](https://github.com/xulicheng1224-arch/guidajia)：MIT，京东/淘宝官方 API 采集实现，没有开放历史库；需自行取得接口权限。
- 部分硬件追踪仓库包含明确标注的模拟价格，未导入为真实记录。

京东、淘宝、慢慢买、ZOL 等站点当前被本环境网络策略拒绝；这不表示它们的服务失效。相关域名可在环境设置中配置后继续验证。即便能连接，官方接口通常仍需要应用权限，也没有验证其能返回 2020 年起逐日历史。

## 导入真实历史记录

点击“导入数据”，下载 CSV 模板，填入有来源的真实报价并导入。Excel 请另存为 CSV UTF-8。必需字段：

```text
product_id,category,brand,name,spec,release_date,date,price,source,url
```

`category` 为 `memory`、`gpu`、`cpu` 或 `storage`；`price` 是正数人民币元，精确到分；`url` 可空，填写时须为 HTTPS。日期不得早于 2020、晚于北京时间今天或早于该型号上市日期。模板的价格刻意留空，避免样例被误当成真实数据。

- 一批有误则整批拒绝，已有记录保留。
- 同型号、同来源、同日期重复导入会去重或更新。
- 不同容量、频率、套条数量、显存、盒装/散片、成色、券后/补贴口径应分清型号和来源。
- 演示导出含 `data_mode=demo`，不能导回真实工作区。
- 页面单次文件限制 5 MB；大文件可拆分。API 限制 20 MB / 100,000 条。

完整校验、API 与采集器协议见 [数据说明](docs/data.md)。

## 每日自动采集

提供获授权的 HTTPS JSON 接口，返回 `{ "records": [...] }`，每条记录与 CSV 的字段相同。安全地在环境中设置 `PRICE_FEED_URL`，接口如需 Bearer 令牌则设置 `PRICE_FEED_TOKEN`。没有预置免费中国全网接口，不需要在聊天中提供密钥。

```bash
npm run collect          # 立即采集一次
npm run collect:watch    # 常驻：启动补采一次，此后北京时间每日 09:00 采集
```

采集器遵守系统 TLS 验证及环境代理，禁止重定向携带令牌。成功后同一北京时间日期不重复自动采集，失败会记录状态。常驻采集器必须由进程管理器维持；环境快照不会保留运行进程，网页的“已配置”不等于采集进程存活。

## 图表与价格口径

每日价为同型号、同一天、各来源报价的最低价。默认每周一根 K 线：周一开始，取实际有记录日的首价、最高、最低、末价。周/月边界和日期均按北京时间。图下柱形是**报价条数，不是成交量**。红色表示上涨，绿色表示下跌。

日线/周线/月线、折线/K 线、预设和自选日期区间均可切换。图表支持鼠标、触屏、左右方向键；较长历史可横向滚动。缺失记录不插值，上市之前不计入覆盖天数。最新涨跌幅只在前一天有记录时显示，历史最低以整个已记录时间段为准，不能推断为“全网历史最低”。

## 数据保存与部署范围

SQLite 默认保存为 `data/prices.sqlite`，被 Git 忽略。`PRICE_DB_PATH` 可指定其他路径。请备份数据库；运行中可用 SQLite backup API，停服后再复制数据库及 WAL 文件。修改前保留自己的原始 CSV。

这是单用户开发看板。若要部署到公网并开放写入，应先添加身份验证、访问控制与持久化卷。没有交易、下单或购买建议功能。

代码位于 `src/`（React + TypeScript）和 `server/`（Express + SQLite）；`tests/` 验证导入事务、去重、币种精度、真实/演示隔离、时间边界、缺失记录、周线聚合、HTTPS 采集与 HTTP API。
