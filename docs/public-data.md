# 公开报价档案与真实覆盖范围

2026-10-21 重新联网调查后，已读取中关村在线和太平洋电脑网的公开产品列表，并整理为 [public-prices.json](../datasets/public-prices.json)。网站默认打开统一“市场总览”，公开报价、历史文章、66 项规格目录和本机导入均可搜索、自选、查看日/周/月线及对比。来源档案页保留独立 CSV/JSON 下载，所有报价口径仍分别统计。

另新增独立[免费历史文章报价档案](historical-data.md)，从 2020 年起的原文找回部分旧记录；按文章日期展示，不混入这里的页面观察日期。

**这不是从 2020 年起的完整价格库，也不是当前可购买价或成交记录库。** 首批为 378 个来源型号、589 条报价观察，实际价格观察日期只有 2026-10-21；以后以 JSON 与网页上的动态统计为准。相同物理产品可能分别出现在两个来源中，来源产品 ID 独立，未经核对不合并为唯一 SKU 数量。

2026-10-22 实跑更新后，档案包含 419 个来源型号、1,193 条观察（2026-10-21 和 2026-10-22 两个日期）；同日多次读取按原规则去重，不将采集次数算成日期数。历史文章另有 297 条，涉及 177 个文章日期。后续以页面实际统计为准。

## 两种报价严格分开

| 类型 | 实际提取的位置 | 能证明什么 | 不能证明什么 |
| --- | --- | --- | --- |
| `reference` 网站参考价 | ZOL 列表 `.price-row .price-type`；太平洋列表 `.price-now` | 采集时，该来源页面展示了这个参考金额 | 价格何时生效、商家现在是否出售、库存、可结算金额或成交 |
| `retailer_relay` 转引电商报价 | ZOL 列表 `.item-b2cprice` 中的京东报价及明确 SKU 链接 | 采集时，该来源页转引了某个商品链接和金额 | 转引的 SKU 与来源型号是否完全一致，当前库存、地区、券、会员、补贴、税费与运费条件，或真实成交 |

不把“参考价”混进电商报价计算最低值；不同来源产品 ID、不同转引 SKU 链接、不同报价口径分别生成走势。`¥1.8万` 等经过四舍五入的文字不是精确金额，解析器不将其转换为 18000 元。

所有记录都有 `verification=source_page_only`、`availability=unknown`、`effectiveDate=null`，以及中文条件说明。`observedAt` 是抓取观察时间，`date` 是该时间对应的北京时间日期；这两个字段都不是价格生效日期。**今天读到一个过时参考价，只能记作“今天观察到来源页显示这个金额”，不能冒充今天真实成交。**

原页面的 ¥721 没有因此被恢复。旧演示目录缺少精确料号，不能仅凭“32GB / 6000 / CL36”绑定到任意新条目。

## 实际来源入口

- 中关村在线：[内存](https://detail.zol.com.cn/memory/)、[显卡](https://detail.zol.com.cn/vga/)、[CPU](https://detail.zol.com.cn/cpu/)、[机械硬盘](https://detail.zol.com.cn/hard_drives/)，各自最多两页。每个记录保留实际列表证据链接、完整型号资料链接，以及可读取时的标注参数。
- 太平洋电脑网：[内存](https://product.pconline.com.cn/memory/)、[消费显卡](https://product.pconline.com.cn/vga/)、[专业显卡](https://product.pconline.com.cn/pro_vga/)、[固态硬盘](https://product.pconline.com.cn/dianziyingpan/)。读取型号、站点提供的参数及参考价。
- 专业卡在太平洋的独立分类页中有记录，但许多型号较旧；这些仍是参考资料，不是宣称当前仍有全新零售库存。
- ZOL 专业卡筛选页本次返回验证跳转，未解验证、未将其当成有效数据。部分普通列表曾返回 403、503 或超时；只保留成功读取的观察。
- 京东搜索返回验证页面；指定商品页面未返回可核实的商品价格。什么值得买搜索返回 HTTP 202 的短页面，未取得可核对商品内容。HTTP 200 本身不等于拿到了有效价格。
- 慢慢买首页及公开历史查询入口已可读取，输入指定京东商品链接后的 HTML 未返回历史价格序列；其当前网页脚本会先检查京东登录/授权状态；实际检查接口返回 `code: 0, login: 0, msg: 请先登录`，尚未取得可导入、可批量再分发的历史档案。未绕过登录授权。
- 集邦网站可读取，但提供国际美元 DRAM 颗粒、模组与 SSD 市场统计，口径与中国零售成品不同，未填入本人民币产品档案。

GitHub 新检查的 `shyss1292-afk/diy-price-report` 与 `forzaferrari255/pc-hardware-tracker` 仍主要是采集/看板代码，没有找到可验证的 2020 年起中国各规格逐日公开数据库。没有直接运行其登录、反爬或模拟价格模块，也没有把其示例金额导入。

## 规格与数据质量

完整来源型号名称保留容量、套装、频率、显存及包装区别。参数只复制来源页明确标注的字段；未标注的条数、CL、盒装/散片或上市日保留未知，不按相近产品猜测。来源数据自身也可能矛盾或过时，网页提供原始型号资料链接供继续核对。部分型号详情页无法读取时，不伪造参数。

GPU 来源分类与可识别的产品系列用于区分消费卡和专业卡；无法确认用途的型号标为“用途待核实”，不把数据中心卡自动算作消费卡。不同来源 ID、不同容量版本不自动合并。

JSON 保留引用金额的证据文字、成功获取时的响应 SHA-256 和列表采集结果。首批部分早期响应只保留结构化结果，未保留完整 HTML 或响应摘要；不能用后来抓取的 HTML 补写成此前的原始证据。详情参数的响应摘要独立于价格证据，抓取详情也不会改变历史报价日期。

## 免费版每日积累

```bash
npm ci
npm run collect:public
npm test
npm run build:pages
```

GitHub Pages 工作流每天 **北京时间 09:15** 计划运行相同采集器，去重、保存到仓库，再构建发布。GitHub 的计划任务可能延迟；站点可能验证、限流或改变结构。采集成功多少、失败多少、最近日期都在网页上展示。整个采集失败时任务失败并保留已发布网站与旧数据，不把旧数据改成当天新价格。单个来源失败不会删除原有记录。GitHub Token 只用于在此仓库保存公开资料，不是电商数据授权。

手动运行 Pages 工作流时可选 `refresh_prices=true` 采集；普通代码推送只构建已有档案。首次补充详情参数可运行 `node --use-env-proxy --use-system-ca scripts/collect-public.mjs --enrich-only`，它只更新规格元数据，不补写价格观察。

## 仍然缺少的“完整版本”数据

1. 2020 年起每个精确 SKU 每一天、同一价格条件下的历史档案。公开采集程序不等于公开了其数据库；今天开始采集无法恢复过去没有保存的数据。
2. 商家直接返回且能核对库存、地区、会员、券、补贴、运费的实际可购价。
3. 若称为“成交价”，必须有成交记录或可用订单凭据；报价不能替代成交。
4. 全网覆盖边界、商家清单和下架/缺货状态；本档案目前只覆盖上述两个公开报价来源的有限列表页。

继续接入官方授权或历史供应商时，先核对精确 SKU、历史日期范围、价格口径、授权与费用，再导入。不能把当前参考价、海外美元价、发布指导价、插值或随机数回填为历史记录。
