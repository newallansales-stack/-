# 价格数据与历史口径

公开网站默认展示独立的[公开报价观察档案](public-data.md)，不发布模拟价格。下文介绍完整版后端：真实数据与演示数据分别存储，默认进入真实记录工作区。演示价格是程序生成的功能示例，不是京东、天猫或品牌的实际报价，不代表曾经的市场价格，也不能证明全网覆盖。演示名称带有“演示”，导出文件包含 `data_mode=demo`，系统拒绝将其导入为真实数据。

## 历史范围与价格定义

- 系统支持 **2020-01-01 至北京时间今天**的历史记录；型号在上市之前没有价格记录。
- `product_id` 对应唯一型号、规格和包装版本；容量、频率、显存、盒装/散片、套装不同需不同 ID。请为真实数据填写核实过的上市日期；演示目录的元数据仅用于界面示例。
- 一个来源、一个型号、一天存储一条人民币成交条件明确的报价。金额以分存储，API 以元返回。
- **每日价格**为当天已收录来源中的最低报价。**历史最低价**为当前数据库中该型号已收录记录的最低价。二者均不能声称是“中国全网最低价”。
- 日涨跌使用最后记录日与其前一自然日的每日最低价；前一天没有数据时返回空值，不拿更早日期冒充昨日。
- 每周从星期一到星期日，一根 OHLC 柱表示本周首个有记录日的最低价（开）、每日最低价的最大值（高）、每日最低价的最小值（低）和末个有记录日的最低价（收）。月线按自然月。首根周线的日期可能是 2019-12-30，它仅代表周起始日，观测记录仍从 2020-01-01 开始。
- **缺失日保留为空白，不补零、不插值、不沿用前一天报价**。周/月柱只汇总实际有记录的日子；整个周期没有记录就没有柱。覆盖率按筛选范围与上市时间计算。
- 来源报价列表仅列该型号最后记录日的报价，过时的其他来源不会伪装成当日报价。

## CSV 导入

在看板内下载模板并填写。文件编码 UTF-8（支持 BOM），支持 Excel 导出的带引号/逗号文本。API：`POST /api/import`，JSON 请求体 `{ "csv": "..." }`。每批最多 20MB / 100000 行。整个批次校验成功后在单个事务写入，失败时不写入任何部分。

| 列 | 含义 |
| --- | --- |
| `product_id` | 1–100 个英文字母、数字、点、横线、下划线；首字符为字母或数字 |
| `category` | `memory` / `gpu` / `cpu` / `storage` |
| `brand` | 品牌 |
| `name` | 型号名称 |
| `spec` | 完整规格与版本，便于同规格比较 |
| `release_date` | 上市日期，`YYYY-MM-DD` |
| `date` | 报价日期，`YYYY-MM-DD`，不早于 2020 或上市日期，不晚于今天 |
| `price` | 人民币元，必须大于零、最多两位小数、不超过 100 万 |
| `source` | 可追溯的来源/店铺/报价类型，建议注明自营、优惠条件等 |
| `url` | 可选的 HTTPS 商品或证据链接，不可包含用户名或密码 |
| `data_mode` | 可选；存在时必须为 `real`，导出的 `demo` 记录不可转成真实记录 |

同一 `product_id` 的品类、品牌、名称、规格、上市日期必须一致；不同规格请使用不同 ID。重复的 `product_id + source + date` 会更新价格/链接，相同记录跳过，可重复导入。模板价格故意留空，避免模板示例被当成真实记录。

示例（**仅展示文件格式，不能当作真实市场报价**）：

```csv
product_id,category,brand,name,spec,release_date,date,price,source,url
your-product-id,memory,你的品牌,你的型号,16GB DDR4 3200MHz,2019-01-01,2020-01-01,199.00,你的历史档案,https://example.com/evidence
```

## 每日采集接入

本项目没有未经授权抓取电商页面、绕过验证码或自动获取付费历史记录的功能。要恢复 2020 年以来每一天的真实价格，需要有覆盖相应时期的历史档案或获授权的数据供应商；如今才开启的采集不能自动恢复过去的价格。

配置环境变量：

- `PRICE_FEED_URL`：获授权的 **HTTPS** JSON 数据源，响应为 `{ "records": [...] }`，每条记录字段与 CSV 一致，`price` 可为数字或字符串。
- `PRICE_FEED_TOKEN`：可选 Bearer token，通过运行环境安全注入。不要把值写进源代码、版本库或聊天。
- `PRICE_DB_PATH`：可选数据库路径，默认 `data/prices.sqlite`。

运行 `npm run collect`（或 `node --use-env-proxy --use-system-ca scripts/collect.mjs --once`）采集一次；运行 `npm run collect:watch`（或 `node --use-env-proxy --use-system-ca scripts/collect.mjs --watch`）保持北京时间每日 09:00 采集。常驻进程启动时若今天尚未成功采集，会立即补采一次。失败不修改已有报价，错误状态显示在 `/api/status`；下一次计划时间可继续重试，人工可执行一次性采集即时重试。Node 的代理与系统 CA 选项保留云环境注入的 HTTPS 代理和证书信任。

采集使用 60 秒超时、20MB 限制、HTTPS 证书校验，并禁止重定向以避免 Bearer 凭据转发到其他主机。系统不向前端暴露 URL 或 token 值；`/api/status` 仅显示是否配置和上次结果。采集进程和 Web 服务是独立进程，重启机器后需要按运行说明重新启动。若平台网络限制外部请求，请在环境设置中添加数据源实际域名；不要关闭 TLS 校验。

当前应用面向单用户开发环境，没有账号/角色权限。生产部署应在可信网络或认证网关之后使用，尤其要保护导入接口；不要将可写 API 裸露给公众。

## 存储和备份

SQLite 文件位于被 Git 忽略的 `data/`，应用启动仅为演示区补充新的演示日期，不会生成真实记录。备份请使用 SQLite 在线备份工具，或先停止 API 和采集进程再复制数据库；WAL 活跃时不要只复制主文件。删除数据库会丢失导入记录；导出的 CSV 可用来迁移真实数据。
